### 7. Offensive Security & Penetration Testing Types
*   **Component:** [Pentest Types Component](file:///c:/Users/pranav/aguna-website/Aguna-portfolio/website-knowledge-base/components/pentest-types.md)
*   **Visuals:** Dark layout displaying a 3-column grid of dark `DynamicBorderCard` items with holographic mouse-tracking glows.
*   **Copy:**
    *   *Heading:* "Types of Penetration Testing"
    *   *Description:* "We conduct targeted penetration testing to simulate real-world attack scenarios and identify exploitable security weaknesses across systems, applications, and infrastructure."
*   **7 Pentesting Models:**
    1.  **Internal Penetration Testing:** Simulates attacks originating from within the organization to identify risks related to insider threats, compromised accounts, and internal network weaknesses. (Icon: Building2)
    2.  **External Penetration Testing:** Evaluates internet-facing systems and applications to identify vulnerabilities that could be exploited by external attackers. (Icon: Globe)
    3.  **Application Penetration Testing:** Assesses web and mobile applications to uncover security flaws in authentication, authorization, input validation, business logic, and data handling. (Icon: Smartphone)
    4.  **Network Penetration Testing:** Examines network architecture, configurations, and security controls to identify weaknesses that may allow unauthorized access or lateral movement. (Icon: Network)
    5.  **Cloud Penetration Testing:** Tests cloud environments to identify misconfigurations, insecure access controls, and exposure risks across public, private, and hybrid platforms. (Icon: Cloud)
    6.  **API Penetration Testing:** Focuses on securing APIs by identifying vulnerabilities related to authentication, authorization, data exposure, and improper access controls. (Icon: Code)
    7.  **Source Code Review:** Analyzes application source code to identify security flaws early in the development lifecycle and reduce the risk of exploitation. (Icon: FileCode)
*   **Purpose:** Map the offensive security catalog, demonstrating capability across all modern technology stacks.
